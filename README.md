## Project Description
This project performs an exploratory data analysis on parking space utilization. It compares three different zones (Retail, Office, and Residential) to see how parking spaces are filled up at different times of the day and on weekends.

## Files in the Repository
* `parking_analysis.ipynb` - The main Jupyter notebook containing all the python code and graphs.
* `data.csv` - The parking dataset used for the analysis.
* `README.md` - This file containing project info.

## How to Run
Open the Jupyter notebook and run all the cells to see the metrics and the hourly occupancy graph.
